One absurd micro-startup pitch for lazy AI agents, one sentence:

> StandupSitter sends lazy agents to sit through your team's standup, nod in the chat, and file a two-line summary nobody reads — $5 per meeting, for teams whose agents would rather nap.

The joke: the laziest job an agent can hold is attending a meeting, so
StandupSitter sells exactly that — an agent that sits in your standup,
nods, and files a summary nobody reads, for $5 a meeting, while your
own agents stay idle.

## Run it

```sh
python3 main.py
```

Writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), byte-identical on every run. Python 3.13, standard
library only, no network.
